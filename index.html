    Before sending a file out

    1. File › Info › Check for Issues › Check Compatibility. Lists every feature that will break in older Excel/Word.
    2. Inspect Document in the same menu. Removes hidden sheets, comments, personal info.
    3. Going outside the company? Send PDF for final numbers, or Paste as values in a copy.
    4. Linked Excel in Word/PowerPoint? File › Info › Edit Links › Break Link on the copy you send.
    5. Power Query files: refresh fails if the source is on your C: drive. Keep sources on SharePoint.
    6. Macros (.xlsm) from email are blocked by default on most PCs. Tell the receiver, or send .xlsx.

    Safe-everywhere swaps

    • XLOOKUP → INDEX + MATCH
    • FILTER / UNIQUE / SORT → PivotTable or Advanced Filter
    • IFS / SWITCH → nested IF
    • GROUPBY / PIVOTBY → PivotTable
    • TEXTSPLIT → Text to Columns or Power Query split
    • Checkbox in cell → Data validation list Yes/No
    • Morph / Zoom slides → normal fade + hyperlinks
    • Power BI for people without a licence → export to PDF/PowerPoint, or an Excel copy

    What IT may block, and why

    10-minute free-time routine

    1. Pick one cardFilter "Not tried yet" + one app. Start with ★ Core cards.
    2. Use a copy of a real fileLast month's export, an old letter, last closing deck. Real data sticks better than tutorial data.
    3. Open the card and follow the stepsOr press Alt + Q in the app and type what you want in plain words.
    4. Look under the hoodRead the formula, the Applied Steps, the recorded macro, or the generated DAX. Understand why, not just how.
    5. Tick the cardThen use it in a real task within the week.

    Suggested order

    1. Excel ★ Core cards (Tables, SUMIFS, XLOOKUP, PivotTable, number formats)
    2. Power Query: folder combine, unpivot, merge (bank rec)
    3. Power BI: star schema, fiscal date table, CALCULATE, RLS
    4. Power Automate: attachments, approvals, Teams post
    5. Word mail merge + PowerPoint slide master + paste-link
    6. Collaboration: Lists, Planner, SharePoint metadata
    7. Coding last: Power Query M, VBA, Office Scripts, Python in Excel

    Golden rules

    • Never practise on the live file. Duplicate first.
    • Never store bank portal passwords in any flow, macro or script.
    • Before pasting company data into Copilot or any AI, check your company's AI policy.
    • If a flow or report runs under your name, add a co-owner so it doesn't stop when you're on leave.
    • Document what you build in a one-page SOP so others can run it.
