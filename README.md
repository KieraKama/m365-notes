# M365 Field Notes

Self-learning notes on Microsoft 365 for finance & accounts work.

- `index.html` – the page (layout and behaviour)
- `data.json` – all the content: features, how-to steps, tasks, versions, IT blocks, licences, change log

The page reads `data.json`, so content updates only touch that file.
`lastChecked` and `changes` in `data.json` show on the page under "Updates & suggestions".
`cusdisAppId` turns on the comment box (from cusdis.com).
